# 🏘️ Granni – Local Community Platform

A neighborhood-focused social platform designed to strengthen local communities through communication, events, and shared experiences.

> Source code is private due to project confidentiality.


## Overview

Granni is a mobile application that helps people connect with others in their local area.

The platform creates a digital neighborhood space where users can:

- Join local groups
- Send messages
- Discover and create events
- Receive local notifications
- Engage with nearby communities

The goal was to make local interaction more accessible and create stronger community engagement.



## Problem

Many social platforms focus on global connections but provide limited support for local communities.

People often miss nearby activities, events, or opportunities simply because there is no dedicated platform for neighborhood interaction.

Granni was designed to solve this challenge by bringing local communication into one place.
